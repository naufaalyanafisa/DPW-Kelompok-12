Modifikasi Website Fakultas Teknik UNRI
Proyek ini merupakan hasil modifikasi tampilan halaman utama web FT UNRI untuk memenuhi tugas UTS Praktikum. Website ini didesain ulang agar lebih modern, estetis, dan responsif.

Teknologi yang Digunakan
HTML5: Menggunakan tag semantik untuk struktur yang lebih baik
CSS3: Flexbox, Grid, dan Media Queries untuk layout responsif
JavaScript: Untuk navigasi interaktif (Hamburger Menu)

Perubahan yang Dilakukan
Navigasi Menu Horizontal dengan Dropdown
Perubahan: Mengubah daftar link vertikal menjadi navbar horizontal dengan dropdown
Alasan: Memudahkan navigasi dan menghemat ruang layar

Hero Section (Banner Utama)
Perubahan: Menambahkan banner besar dengan teks selamat datang
Alasan: Memberikan kesan pertama yang profesional dan modern

Layout Grid untuk Informasi
Perubahan: Mengubah daftar teks menjadi card dengan ikon
Alasan: Lebih mudah dibaca dan menarik secara visual

Responsive Design
Perubahan: Menambahkan media queries untuk berbagai ukuran layar
Alasan: Website dapat diakses dengan baik di laptop, tablet, maupun smartphone
